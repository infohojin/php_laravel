# 라라벨 문서

[https://laravel.com/docs](https://laravel.com/docs)에서 Laravel 문서의 온라인 버전을 찾을 수 있습니다.

## 기여 지침

**현재 안정 릴리스**에 대한 문서를 제출하는 경우 해당 브랜치에 제출하세요. 예를 들어 Laravel 12에 대한 문서는 `12.x` 브랜치에 제출됩니다. Laravel의 다음 릴리스를 위한 문서는 `master` 브랜치에 제출되어야 합니다.
