지니와 도로시의 라라벨 기반
쇼핑몰(JinyShop) 핸드온 개발

마법사 고양이 지니, 주니어 개발자 도로시, 디버깅 보조견 토토와 함께
온라인 서점 '지니샵(JinyShop)' 스토어프론트 & 관리자 백오피스를 직접 구축하며
라라벨 13.x 최신 공식 문서(103개 전 주제)를 100% 체화하는 14주 마스터 클래스입니다!

14주 핸드온 실습 시작 ➔ 라라벨 공식 문서 (docs) ➔
📚 라라벨 공식 문서 100% 매핑 안내 (11개 그룹, 103개 주제 전수 체화)

본 교육 과정은 라라벨(Laravel) 최신 공식 문서를 기반으로, 방대한 공식 문서의 레퍼런스를 단 하나도 생략하거나 축소하지 않고 온라인 도서 쇼핑몰 지니샵(JinyShop)의 14주 핸드온 개발 맥락에 맞추어 완벽하게 분리·병합·재배치하여 체화할 수 있도록 제작되었습니다.

🗺️ 지니샵(JinyShop) 14주 핸드온 로드맵

고객용 스토어프론트와 운영자용 관리자 백오피스를 동시에 구축하는 4단계 듀얼 트랙(Dual-Track) 마스터 과정입니다.

1단계 (01~04주차)

코어 기초 & 프로젝트 킥오프

Laravel Sail / Herd 개발 환경 구축, Slim 디렉터리, 요청 생명주기, 라우팅, 블레이드 UI 컴포넌트, DB 마이그레이션과 1,000권 도서 대량 시딩을 완료합니다.

01주차 실습 시작 ➔
2단계 (05~08주차)

Eloquent ORM & 보안/인증

도서 카탈로그 다조건 검색, 모델 관계(1:N, N:M, MorphMany)와 N+1 쿼리 최적화, 장바구니 세션 시스템, 고객 vs 관리자 멀티 가드 인증 및 Policy 인가를 구현합니다.

05주차 실습 시작 ➔
3단계 (09~11주차)

아키텍처 & 비동기 결제

도서 표지 WebP 파일 업로드, 관리자 전용 대시보드 CRUD, 서비스 컨테이너 & 커스텀 PG 결제 파사드, DB 트랜잭션, Redis 비동기 큐와 Horizon 모니터링을 완성합니다.

09주차 실습 시작 ➔
4단계 (12~14주차)

실시간 웹, AI & 프로덕션 배포

대화형 아티산 CLI 재고 입고 도구, 미결제 자동 취소 크론, Reverb 실시간 웹소켓 주문 토스트, Laravel AI SDK 도서 추천, Pest/Dusk 테스트 자동화 및 Envoy 배포를 완성합니다.

12주차 실습 시작 ➔
Reference (106편)

라라벨 공식 문서 (docs)

라라벨 13.x 최신 공식 영문 문서 전편에 대응하는 100% 한국어 번역본 아카이브입니다. 실습 도중 언제든 공식 레퍼런스를 깊이 있게 교차 검증할 수 있습니다.

공식 문서 열람 ➔
Hands-on (14주 56강)

통합 핸드온 실습 로드맵

14주 56강 전 강좌에 대한 단계별 학습 목표, 듀얼 트랙 시나리오, 실습 코드 스펙 및 전체 목차를 한곳에서 편리하게 확인하고 시작하세요.

🐱 지니 (Jiny)

👧 도로시 (Dorothy)

주니어 풀스택 개발자

성장형 주인공! 초보자의 눈높이에서 날카로운 질문을 던지고, 직접 터미널에 명령어를 치며 지니샵의 기능을 하나씩 구현해 나갑니다.

🐶 토토 (Toto)

실무 트러블슈터 & 가이드

도로시의 충직한 개발 보조견! 초보자가 범하기 쉬운 실수, 에러 해결 팁, 유용한 CLI 단축키를 꼬리를 흔들며 멍멍 짚어줍니다.
